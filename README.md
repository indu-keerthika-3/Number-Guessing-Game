🎯 Number Guessing Game

A simple and fun command-line game built with Python where the player tries to guess a randomly generated number between 1 and 100 within 7 attempts.

📌 Features
🎲 Random number generation between 1 and 100.
🔢 Maximum of 7 attempts to guess the correct number.
📈 Hints to help you guess higher or lower.
⚠️ Input validation to handle invalid entries.
🎉 Displays a success message when you guess correctly.
❌ Reveals the secret number if you run out of attempts.
🛠️ Technologies Used
Python 3
Random module (Python standard library)
📋 Requirements
Python 3 installed on your computer.
A terminal or command prompt to run the game.
🚀 How to Run
Clone this repository:
bash
git clone https://github.com/indu-keerthika-3/Number-Guessing-Game.git

Navigate to the project directory:
bash
cd Number-Guessing-Game

Run the Python program:
bash
python number_guessing_game.py


If your system uses python3, run:

bash
python3 number_guessing_game.py


Replace number_guessing_game.py with your actual Python filename if it is different.

🎮 How to Play
Run the program.
Enter an integer between 1 and 100.
Read the hint:
Too low! — Try a higher number.
Too high! — Try a lower number.
Keep guessing until you find the secret number or use all 7 attempts.
Enjoy the game!
💻 Example Output
text
